# 【重要提醒 · 请勿随意升级 LangChain】
# 本项目锁定 LangChain 0.3 系，因为课程笔记里的写法是：
#     from langchain.agents import AgentExecutor, create_react_agent
#     from langchain_core.prompts import PromptTemplate
# 这套导入路径属于 0.3 系 API。
# 如果装成 langchain 1.x，上面这些类会搬到 langchain-classic 包里，
# agent_service.py 第一行 import 就会失败。
# 所以：不要手动 pip install -U langchain，也不要删掉下面的版本号。
